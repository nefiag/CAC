## 1. 分析对象与证据

- 官方个人版压缩包：`xiaokuaiji3.0personal.zip`

## 2. 操作员心智模型

官方界面的主流程是：

`操作员 → 凭证录入 → 凭证审核 → 凭证记账 → 凭证查询 / 明细分类账 / 科目余额表 / 财务报表`

关键交互特征：

1. 顶部按业务域切换：账务处理、财务报表、银行对账、往来核算、合同管理等。
2. 登录后首先看到“业务导航”，而不是单一功能页。
3. 查询页使用高密度表格和传统工具栏（范围、联查、求和、设置、导出、打印、预览）。
4. 账簿和报表可跨月查询，并可包含未记账凭证。
5. 凭证录入强调键盘流、快速找平、科目模糊检索和保存后连续新增。
6. 参数集中控制凭证编号、审核/记账约束、辅助核算、打印显示和自动备份。

## 4. 本轮迁移改造

- 产品标识使用 `Coxiaoac`，以“经典财务工作台”描述迁移模式，避免冒充原产品。
- 将原来的深色左侧 AI 菜单改为个人版用户熟悉的顶部业务域导航。
- 默认打开业务导航，并用流程节点连接已有凭证、账簿和报表页面。
- 银行智能处理归入“银行对账”，不再抢占默认首页。
- 凭证日期跟随所选会计期间，移除固定日期。
- 会计期间根据账套当前年度生成，移除固定 2026 年列表。
- 增加底部状态栏，持续显示账套、期间、凭证数量和系统状态。
- 补齐合同、往来和账套参数的真实持久化页面，不保留无业务结果的假按钮。
- 迁移流程增加文件结构、必需列、重复科目、未知科目和凭证借贷平衡预检；导入凭证统一进入草稿复核。

## 5. 后续优先级

1. 为已完成的凭证状态机补充用户权限和操作审计字段。
2. 在已有三级联查上增加跨月范围、总账和多栏账样式。
3. 建立单位、个人、部门、项目等辅助核算维度及组合余额表。
4. 实现账套复制、批量备份和晓会计导出数据的迁移校验报告。
5. 在现有合同台账和收付款计划上增加凭证自动核销；补现金流量自动归类。
